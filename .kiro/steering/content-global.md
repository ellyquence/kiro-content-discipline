# Content Standards (Quick Reference)

## Core Principles
1. Clarity over cleverness
2. Value over volume  
3. Reader-first
4. Evidence-based (3+ sources required)

## Quality Checklist
- [ ] Grade 8 readability
- [ ] 3+ credible sources
- [ ] Clear CTA
- [ ] E-E-A-T signals present
- [ ] Brand voice consistent

## Workflow
Brief → Research (R1-R4 gates) → Outline → Draft → Review → Publish
