# Quality Gates (Quick Reference)

## Gate Checklist

**G1: Brief** - Audience, keyword, goal, competitor analysis, framework chosen  
**G2: Outline** - 25+ headlines, H2/H3 structure, sources identified  
**G3: Draft** - All sections written, word count ±10%, readability ≤ Grade 8  
**G4: Editorial** - Voice consistent, structure clear, facts verified  
**G5: SEO** - Meta title/desc, keywords placed, E-E-A-T signals  
**G6: Final** - Image ready, social snippets, publish scheduled

## Failure Protocol
Document → Return → Revise → Resubmit
