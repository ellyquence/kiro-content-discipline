# Content Frameworks (Quick Reference)

## Choose Framework by Goal

| Framework | Use When | Structure |
|-----------|----------|-----------|
| **AIDA** | Awareness, conversions | Attention → Interest → Desire → Action |
| **PAS** | Problem-solving | Problem → Agitation → Solution |
| **BAB** | Transformation | Before → After → Bridge |
| **How-To** | Education | Overview → Steps → Troubleshooting |

## Quick Patterns
- **AIDA**: Hook → Build curiosity → Show benefits → CTA
- **PAS**: Name pain → Dig into consequences → Present solution
- **BAB**: Current state → Desired state → How to get there

**Full frameworks with examples**: `.kiro/reference/structure-frameworks-full.md`
