# Reference Files

These files contain full examples, templates, and detailed explanations.

**They are NOT loaded automatically by Kiro.** Reference them manually when needed:
- When outlining: `#structure-frameworks-full`
- When writing headlines: `#headlines-full`
- When checking readability: `#readability-full`
- When optimizing SEO: `#seo-eeat-full`

## Why Separate?

Steering files load every session. Keeping them lean (~40 lines each) reduces:
- Context window usage
- Token costs
- Cognitive load

Full examples are here when you need them, but don't consume context when you don't.

## Files

| Reference | Contains |
|-----------|----------|
| `structure-frameworks-full.md` | Full AIDA, PAS, BAB, 4Ps, Story Arc, How-To outlines |
| `headlines-full.md` | 10 headline formulas, power words, A/B test ideas |
| `readability-full.md` | Word substitutions, examples, visual rhythm, tools |
| `seo-eeat-full.md` | Schema markup, intent alignment, freshness checklist |
